INVESTIGATION GUIDANCE
When checking whether a deployment contributed to an outage:
1. Align incident, log, metric, and deployment timestamps using the same timezone.
2. Compare the last known-good version with the current version.
3. Review code, configuration, secrets rotation, infrastructure, and dependency changes.
4. Check whether error rates change after a controlled rollback or fix.
5. Record alternative explanations and evidence that would disprove the leading hypothesis.
6. Follow change-management rules; never perform a production rollback solely because a model suggested it.
